# 口语中级 001 · 寒暄近况 · 最近忙得团团转，都没时间喘口气。
中文：最近忙得团团转，都没时间喘口气。
英文：###I've been running around like crazy lately and haven't had a minute to breathe.###
用法：run around like crazy 指忙得团团转；haven't had a minute to… 没空做……

B: ###I've been running around like crazy lately and haven't had a minute to breathe.###
