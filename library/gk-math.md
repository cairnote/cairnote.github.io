# 高考数学 03 · 一元二次不等式（a > 0，Δ > 0，x₁ < x₂）
分类：不等式
x₁，x₂ 是方程 ax² + bx + c = 0 的两个不相等的实数根，ax² + bx + c > 0 的解集为 ###{x | x < x₁ 或 x > x₂}###；ax² + bx + c < 0 的解集为 ###{x | x₁ < x < x₂}###

# 高考数学 10 · 函数奇偶性
分类：函数
设函数 f(x) 的定义域为 D，如果 ∀x ∈ D，都有 ###−x ∈ D###，且 f(−x) = ###f(x)###，那么 f(x) 叫做偶函数；如果 ∀x ∈ D，都有 ###−x ∈ D###，且 f(−x) = ###−f(x)###，那么 f(x) 叫做奇函数
<!-- /leiji-note -->

# 高考数学 11 · 函数零点存在定理
分类：函数
如果函数 y = f(x) 在区间 [a, b] 上的图象是一条###连续不断###的曲线，且有 ###f(a)f(b) < 0###，那么，函数 y = f(x) 在区间 (a, b) 内###至少有一个零点###，即存在 c ∈ (a, b)，使得 f(c) = 0
<!-- /leiji-note -->

# 高考数学 22 · a·sinx + b·cosx 化为 A·sin(x + φ)
分类：三角函数
设 a·sinx + b·cosx = A·sin(x + φ) = A·sinx·cosφ + A·cosx·sinφ，于是 ###A·cosφ = a，A·sinφ = b###；取 A = ###√(a² + b²)###，则 cosφ = ###a/√(a² + b²)###，sinφ = ###b/√(a² + b²)###
<!-- /leiji-note -->

# 高考数学 63 · 导数的定义
分类：导数
如果当 Δx → 0 时，平均变化率 Δy/Δx 无限趋近于一个确定的值，就把这个值叫做 y = f(x) 在 x = x₀ 处的导数（也称为瞬时变化率），记作 f′(x₀) 或 y′|ₓ₌ₓ₀，即 f′(x₀) = ###lim(Δx→0) Δy/Δx### = ###lim(Δx→0) [f(x₀ + Δx) − f(x₀)] / Δx###

# 高考数学 65 · 基本初等函数的导数（一）
